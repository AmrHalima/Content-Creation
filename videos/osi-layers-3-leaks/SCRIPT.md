## Constraint audit (run against this script before any TTS was spent)

- **Every leak claim checkable:** Ethernet = a wire you transmit on when you like; Wi-Fi = a
  shared radio where you contend for the air; ARP = answers a Layer 3 question using a Layer 2
  frame. The switch/MAC point and the sublayer point are stated **on screen** (Frame 3 labels)
  rather than spoken, to keep Line 3 to one collision. Full documented list:
  `series-bible.md` § 5.
- **Contrast-reveal ban:** no "not X, Y". Line 4 negates a purpose ("its job was never to
  describe hardware"), then Lines 5 and 6 state the positive use outright and concretely.
- **Negation-list ban:** none. Line 5 originally opened "No link at all: the bottom" and ran
  three colon labels in parallel. Cut — that was a negation list plus a colon reveal in the
  same breath, the two most-flagged AI tells in the series' single most important line. It now
  names three affirmative symptoms.
- **Colon reveal / self-narration ban:** Line 1 originally ended "Now the honest part" — a
  throat-clearing drumroll. Cut; it now names the layer instead. No colons, no rhetorical
  questions anywhere in the part.
- **Em-dash ban on short copy:** none, in narration or on screen.
- **Triad cap:** exactly one — Line 5's three symptom→layer points. Grammar varies across them
  ("sits at" / "are" / "is"), so it does not become a parallel-opener list. Nothing else
  enumerates.
- **No mnemonics:** none.
- **Scoped postal image:** not used in this part.
- **Sideways frame re-established in the first two VO lines:** Line 1 says it outright before
  any new claim. A viewer arriving here first is oriented inside 10 seconds.
- **Zero references between parts:** no "part", no "as we saw", no "last time".
- **No commands, no tool names:** the pointing is teachable without a terminal, so none appear.
