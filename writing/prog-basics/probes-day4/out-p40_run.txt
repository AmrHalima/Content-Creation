identity vs value, the reason immutability is what makes a tuple hashable:
  a == b: True | same object: False
  after a[0] = 9 -> a is [9, 2] and b is still [1, 2] (two separate lists)
  the printed a really did change: True | b untouched: True
  (1,2) == (1,2): True | hash equal: True
  tuple value can never drift, so its hash can never drift - that is the whole argument
  for 'a tuple of hashable items can be a dictionary key', and why the list version cannot.
